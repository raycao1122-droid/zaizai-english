# 在在学习 - AI 英语课堂前端规范 V1.0

## 目标和范围
构建给小学四年级学生使用、平板横屏及桌面浏览器优先的 AI 英语教学工作台。当前阶段只做 **高保真前端与模拟状态**，不接入 OpenAI Realtime、数字人模型、实时发音评估、摄像头、教材解析或正式数据库。视觉和功能须同时验收。课堂以 `Lesson 01 · Animals` 为样例，不代表正式学校教材内容；未来导入教材后要动态生成课程。

## UI 风格
**A+B 融合风格**：温暖生动的教师角色 + 现代简洁的蓝白课堂，不低幼、不做办公系统风格。主色参考蓝 `#327EF3`、浅背景 `#EFF6FF`、深蓝字 `#15356B`，辅色浅绿、奶油黄、柔粉。圆角卡片、微弱阴影、足够留白。具体画面以视觉参考为准。中文产品导航、英文课堂语言，中文翻译仅在提示或设置打开时显现。

## 页面框架
- 顶部：品牌「在在的英语课堂」、上课/课程/单词本/错题本/学习报告导航、用户信息。当前第一阶段其他导航可进入「待开发」占位页，不允许静默无效。
- 课堂主体：**左侧 Emma 约20% / 中间动态课件约60% / 右侧对话面板约20%**；比例指课堂主体宽度，可因常见分辨率适度调整。
- 左侧：固定 Emma 形象、简单动作表现、说话/倾听/思考等标签。**第一版仅静态图+CSS微动，不承诺唇形同步**。
- 中间：单元标题、阶段进度、英文提问、图片/课件卡片和操作提示。动物示例：dog、cat、bird、rabbit，可扩展 fish。
- 右侧：可收起的辅助面板，切换「课堂对话 / 学习提示 / 课堂笔记」；收起后中间课件扩展。只突出当前对话，历史记录可滚动查看。
- 底部：常驻音频状态、静音开关、暂停/退出、语速状态、演示推进按钮。**默认连续语音的交互视觉设计**，非按住说话；本阶段麦克风仅状态模拟。
- 支持电脑浏览器及平板横屏（例如 1280x800、1440x900、1920x1080），避免截断、覆盖、横向溢出；更窄屏幕允许面板折叠。

## Emma 固定形象
棕色盘发、米白针织衫、明亮自然表情、动画电影感的卡通女教师。不得自建其他人物。真正 Live2D/2D 动态人物属于未来阶段。可以为不同状态做轻微缩放/淡入/浮动，但不能把单张图说成可驱动数字人。

## 课堂流程：11 个 UI 状态（整体在一个课堂框架内进行）
1. 课堂准备：Emma 打招呼、开始按钮。
2. 自然问候：展示英文问候和在在回答（模拟）。
3. 认识动物：展示图片、单词和音频按钮（第一版音频按钮明确为模拟）。
4. 听说互动：按提示选中正确图片，显示明显选中状态。
5. 发音纠正：专门的纠错卡、目标单词、示范、重试、重点发音提示（仅演示，不产生真实发音分数）。
6. 句型练习：`What's this?` / `It's a ...` / `I like ...`。
7. 情景对话：围绕喜欢的动物、是否养宠物自然问答。
8. 课堂复习：新图片或简单变式复习，避免只背诵原题。
9. 给在在的课后总结：简短、正向、儿童友好，不泛滥夸奖。
10. 给家长的课后报告：记录词汇、句型、独立回答、提示次数、发音问题、下节课建议；**所有数字为模拟必须标识**。
11. 长期英语档案：显示趋势、复习标记和历史练习；模拟数据有明显说明。

## 语音状态机
`speaking`（Emma 讲话、字幕）/`listening`（在在回答、动态声波）/`thinking`（AI 等待处理）/`correcting`（纠错）。支持 `muted` / `paused` / `disconnected` / `idle`。第一阶段用模拟按钮切换状态，严禁请求真实设备权限或假称调用 API。未来集成时允许在在打断 Emma；静默时先等待、然后温和换问法、再中文辅助，不反复催促。

## 教学规则（后续 AI 接入时生效）
- 教材决定学什么，孩子的历史学习记录决定怎么教、进度如何。
- 老师自然交谈、一次推进一个目标；不机械逐词纠错，不抢话；影响理解的发音优先处理。
- 会读一次不等于掌握，必须跨场景和间隔复习验证。
- 需要保留学习证据；不能凭空编造音频识别、口语成绩或掌握百分比。

## 教材与资料架构（后续阶段）
预留教材库，后续可导入学校教材 PDF、扫描页、Word/PPT、教辅、课堂参考和音频；教材定教学目标、优秀教学资料供参考方法、学习档案用于个性化备课。付费/受版权保护资源不得未经授权抓取和再分发。第一阶段只预留入口/数据接口。

## 组件和数据层建议
React、TypeScript、Vite、Tailwind CSS；拆分 `ClassroomLayout`、`EmmaAvatar`、`LessonStage`、`InteractiveMaterial`、`ConversationPanel`、`VoiceControlBar`、`PronunciationFeedback`、`StudentLessonSummary`、`ParentLessonReport`、`CurriculumLibrary`。课堂数据和 UI 状态隔离，避免把所有逻辑放进一个页面组件。准备 `mockLesson`, `mockConversation`, `mockStudentProgress`，所有演示信息显著标注。

## 里程碑
**M1（先做，必须验收）**：主框架、高保真布局、Emma 静态展示、动物图片点选/正确错误反馈、右侧面板折叠、基本进度、语音模拟状态、可演示退出/重进。
**M2（M1 验收后）**：完整 11 状态、模拟发音纠正、课后报告、长期档案、教材入口。
**M3（另行规划）**：接入真实实时语音、动画驱动、儿童发音评估、教材与学习数据服务。

## 技术和可维护性
不能将整张设计截图作为网页背景冒充前端；必须独立组件化实现。动物课件应拆出独立可替换图片文件；素材若暂缺，可先使用简洁占位图，并说明不能视为视觉定稿。所有控件需有有效行为，不能只是装饰。提交前提供至少三张实际网页截图，并写出与参考图的差异。
