# Codex 执行指令

你正在开发 **在在学习 - AI 英语课堂前端**。这是一个**严格视觉还原 + 分阶段实现**任务，不是重新设计 UI 的开放任务。

请依次执行：
1. 列出并阅读 `assets/` 下三张真实 PNG，检查尺寸及可视内容；先阅读 `FRONTEND_SPEC.md` 和 `ACCEPTANCE_CHECKLIST.md`。
2. 在项目中建立 React + TypeScript + Vite + Tailwind CSS 工程（如已有项目，优先复用，勿覆盖无关文件）。
3. 只完成 **里程碑 M1**：横屏课堂三栏布局、Emma 角色区域、动物图片点选互动、右侧对话/提示面板及折叠、底部语音 UI 模拟、课程进度。不可擅自延伸为完整后端。
4. 保持与 `02_classroom_layout_reference.png` 尽可能一致：清爽蓝白色、柔和圆角、左侧约20%、中间约60%、右侧约20%，下方控制栏。Emma 造型以 `01_emma_character_reference.png` 为准，课堂环节参考 `03_lesson_storyboard_reference.png`。
5. 使用可编辑 HTML/CSS 组件，不得将整张设计图铺成界面背景；可以从原角色图裁切用于暂时展示，但需在交付说明写明裁切来源及缺点。请优先保留现有角色外观，不要使用不相关人物替代。
6. 任何没有真实实现的语音、摄像头、发音评分、AI 教学、教材解析，必须标注「模拟 / 尚未接入」。不能产生假的真实结果。
7. 跑起前端，进行交互测试并提供运行截图，逐条核对验收清单。列出无法还原的部分及原因。
8. **M1 验收前不要自行实施 M2**；在报告中说明已完成的功能和待办项。

缺少素材或遇到冲突时先在报告明确指出，不得自行换风格、删减核心区块或重构设计。
