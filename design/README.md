## 资源限制
原图是完整合成设计稿，**并非**可直接用于动画的分层 Live2D、骨骼模型或单独的透明人物立绘。第一阶段可对原图进行合理裁剪作为静态临时角色展示，但不可宣称已实现实时嘴型同步；要制作正式立绘需后续进行单独素材拆分与授权审查。UI 截图不可简单作为整页背景伪装可交互界面。三个视觉稿均为设计参考，不能替代独立实现的组件。

## 开发顺序
1. 校验全部素材可以读取。
2. 实现第一个可验收里程碑：主界面三栏布局、Emma 静态区域、动物课件识词交互与反馈、右侧面板展开/收起、底部语音模拟状态。
3. 运行并截图对比设计图；待用户确认再继续后续阶段（发音纠正、报告、课程资料）。
