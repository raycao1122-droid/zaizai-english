# ZAIZAI ENGLISH · 第一单元交付包

- `Zaizai_English_Unit1_StudentBook.pdf`：学生教材、四课内容、练习、综合测评、答案。
- `Emma_Teacher_Guide.md`：完整课堂节奏、示范话术、分层纠错、评价逻辑。
- `unit1_course.json`：供 Codex 映射课程引擎的结构化课时数据。
- `assets/`：AI 原创情境插画，不是从《Let’s Go》或学而思教材复制的图片。

**使用边界**：这是一套原创课程内容包，不等于当前网页已经实现导入教材或自动上课；Codex 需要将 JSON/素材映射到现有课件组件、课堂状态和实时语音适配器，并完成测试。插画中的 Emma 是情境示意，不能替换项目原有 `emma.svg`。

**教学定位**：四年级英语基础较弱、听说优先并衔接学校常用句型。使用前建议由教师或家长核对学生实际水平。
